# 踹踹APP Demo - 大学生旅行搭子匹配平台

## 📱 项目简介

**踹踹APP Demo** 是一个AI驱动的大学生旅行搭子匹配平台Demo，重点展示AI产品场景设计能力、AI工具运用能力、产品需求落地能力、前端交互思维。

### 核心功能

1. **AI智能旅伴匹配** - 基于加权算法计算匹配度，用雷达图透明展示AI决策逻辑
2. **AI个性化路线规划** - 分步生成3套差异化方案，给出可解释的推荐理由
3. **基础聊天交互** - 一对一聊天，含AI智能助手快捷提问
4. **AI旅行洞察** - 用户旅行画像分析与个性化推荐

### 技术栈

- **前端框架**: React 18
- **构建工具**: Vite
- **样式方案**: Tailwind CSS
- **路由管理**: React Router v6
- **状态管理**: React Hooks (useState, useEffect)

### 设计特点

- 📱 桌面端采用375px手机模拟器框架展示
- 🎨 年轻活力的UI设计，圆角卡片风格
- 🤖 AI场景可视化（雷达图、生成动画、推荐理由）
- 📊 环形进度条展示匹配度
- 🎭 平滑的页面切换动画

## 🎨 核心AI功能演示

### AI智能旅伴匹配

**演示流程**:
1. 首页点击"搜索"进入搜索页
2. 输入旅行需求（目的地、日期、预算、兴趣）
3. AI计算匹配度，展示匹配结果列表
4. 点击用户卡片查看详情
5. 查看AI匹配分析（雷达图 + 推荐理由）
6. 可查看匹配算法代码

**匹配算法权重**:
- 目的地匹配: 40%
- 出行日期匹配: 25%
- 兴趣标签重合度: 20%
- 预算范围匹配: 10%
- 出行风格匹配: 5%

### AI个性化路线规划

**演示流程**:
1. 点击底部"路线"Tab进入AI路线页
2. 点击"自定义需求"输入旅行偏好
3. 点击"AI生成路线"按钮
4. 观看AI生成过程动画（分步展示）
5. 查看3套差异化路线方案
6. 点击方案查看详情（每日行程 + AI推荐理由）
7. 可查看路线生成算法代码

**生成过程动画**:
- 步骤1: AI正在分析您的需求
- 步骤2: 正在匹配目的地热门景点
- 步骤3: 正在规划行程节奏
- 步骤4: 正在核算预算明细
- 步骤5: 路线生成完成

## 📊 数据说明

本项目采用全量前端Mock数据，无需后端支持：

- **用户数据**: 5个模拟用户，包含完整的个人信息、旅行偏好、历史评价
- **路线数据**: 3套西安旅行方案（美食深度游、历史文化游、网红打卡游）
- **聊天数据**: 2个模拟对话，包含历史消息
- **个人数据**: 用户画像、AI洞察、个性化推荐

所有数据位于 `src/data/mockData.js`
